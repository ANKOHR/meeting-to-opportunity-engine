# Lessons for KOML

The domain requires distinguishing recorded commitments from conversational interest. Raw notes alone do not establish an owner, deadline or proposal request. Encoding those facts explicitly makes action generation auditable but creates an operator entry cost that real use must test.

Synthetic evidence validates the narrow assumption that a fixed mapping of explicit outcomes can recover all planted actions with exact counts and stated amounts. It does not validate the assumption that Henry will use this daily or save time. Ambiguous outcomes are rejected rather than inferred, and negated/no-fit cases produce no action.

Operating rule: before automating interpretation, write the smallest explicit schema and independent expected answers. Never substitute synthetic accuracy for measured usefulness. The first improvement is rejecting ambiguous qualification and mixed currencies; adversarial tests support those decisions. Revisit the top real error cause after the two-week window.
